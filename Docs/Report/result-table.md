### 후처리 효과별 비교
같은 플레이 세션에서 값만 바꿔 비교(정지 좀비, 1-3 최종 조명 상태, 시점 yaw 45°). 에셋은 측정 후 원래 값으로 복구. 5초 창 3회의 중앙값(창 중앙값의 최소~최대). **GPU ms는 `FrameTimingManager.gpuFrameTime`** (D3D12)이며 이번 비교의 핵심 지표다.

> **Frame(CPU) ms는 이 표에서 판단 근거로 쓰지 않는다.** 이 구간은 CPU 쪽이 병목(CPU ≈8~10ms, GPU ≈2ms)이고, 세션 내내 시간이 지나며 프레임 시간이 7.7→10.5ms로 단조 증가(열/클럭 변동 추정)해 구성별 차이보다 드리프트가 더 크다. GPU ms, Batches, SetPass는 드리프트와 무관하게 안정적이었다.
